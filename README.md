# 装前安检 · preinstall-check

> 装了二十个 skill，没一个你看过里面写了什么。跑一次，每个技能出一张卡片：会不会碰私钥、有没有偷偷联网、能不能真跑起来、跟已有功能是不是重复。

装之前先看一眼，免得装完才发现它会读你的 SSH 私钥。默认体检本机已装的全部 skill，也可以指定单个包或 zip。结论分「可以装 / 谨慎装 / 不装」三档，每条指到具体文件某一行，**全程不执行被审代码**。

## 先看效果（任何机器上都能复现）

```bash
python scripts/audit.py --demo
```

样本在运行时生成到临时目录、跑完即删，不随产品分发——免得被人当成可复制的模板。不需要预装任何 skill，也不需要联网。机器上一装了 skill，默认命令就会自动体检它们；一个都没装时会自动降级到这两个演示样本，不会空手退出。

```
==============================================================
装前安检报告   启发式评分，有误差，不是安全审计
==============================================================
结论：共 2 个包 — 1 个建议卸掉，1 个可以留
最该先看：env-sync 35.0（[判死] 脚本引用本地凭证存储路径）
==============================================================
```

每一行结论后面都跟得上一句「为什么」和「去第几行看」。不是「我觉得它不好」，是「脚本第 11 行打开了 `~/.ssh/id_rsa`」。

## 四类检查

| 查什么 | 怎么判 |
| --- | --- |
| 碰凭证 | 脚本是否引用 `~/.ssh`、`.env`、token、凭证存储路径 |
| 偷偷联网 | 是否有未声明的网络调用、数据外发 |
| 能不能跑 | 入口脚本是否存在、依赖是否声明、有无语法级断裂 |
| 功能重复 | 与已装 skill 的触发场景和产出是否高度重叠 |

## 它不做什么

- 不执行被审代码——所以看不出它「算得对不对」，只看得出它「打算做什么」。
- 启发式判断，会漏也会误报。这是体检，不是安全审计。
- 不修改被审文件，只读。

## 装成 Skill 用

复制整个目录到 `~/.workbuddy/skills/preinstall-check/`，然后说「帮我看看我装的这些 skill 有没有问题」。也可以直接跑脚本：`python scripts/audit.py [目录或zip]`。入口是 [`SKILL.md`](SKILL.md)。

## 目录

```
preinstall-check/
├── SKILL.md                  触发场景、判定流程、报告格式
├── DESIGN-NOTES.md           设计判断、评分依据、已知缺陷
├── scripts/
│   ├── audit.py              入口，含 --demo 与自动降级
│   ├── checks.py             规则清单
│   ├── loader.py             载入目录/zip/已装 skill
│   ├── score.py              启发式评分
│   ├── report.py             报告渲染
│   └── demo.py               运行时生成演示样本
├── references/               危险信号与评分细则
└── tests/                    真实 skill 样本的审计报告留档
```
